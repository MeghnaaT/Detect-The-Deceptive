# Detect the Deceptive

AI-powered system for detecting synthetic media (deepfakes, AI-generated content)
with explainable machine learning.

## Features
- FastAPI backend
- Image deepfake detection
- Grad-CAM visual explainability
- Modular ML architecture

## Tech Stack
- Python, FastAPI
- PyTorch
- EfficientNet
- OpenCV

## Status
In active development.
